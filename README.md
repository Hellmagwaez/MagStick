# 🪄 ReachExtender
**Автор:** HellMagWaez
**Версия:** 1.0
**Поддержка:** Minecraft 1.21.10 (Spigot, Paper, Purpur)

## 📝 Описание
**ReachExtender** — это уникальный плагин, добавляющий магический артефакт, который увеличивает дальность взаимодействия с блоками (строительство и ломание).

Больше никаких строительных лесов! Просто возьмите предмет в левую руку, и ваша рука "удлинится".

## ✨ Особенности
* ⚡ **Динамическая система:** Дальность меняется мгновенно при смене предмета.
* 🛠 **Полная настройка:** Настройте предмет, дистанцию и лор в конфиге.
* 🔮 **Уникальный ритуал:** Игроки должны создать предмет с помощью молнии.
* 🚀 **Без лагов:** Использует современные Атрибуты Minecraft 1.21 (Attribute API).

---

## 🌩 Как получить (Ритуал)
Игроки могут создать "Магическую Палку" в выживании с помощью опасного ритуала:

1.  Возьмите обычную **Палку** в **Правую руку**.
2.  Возьмите **Дыхание Дракона** в **Левую руку**.
3.  Получите удар **Молнией** (во время грозы или от трезубца с чарами "Громовержец").
4.  ⚡ **Результат:** Дыхание дракона поглотится, а палка зарядится энергией!

---

## ⚙️ Команды и Права

### Команды
* `/getreachstick` — Выдать себе магическую палку (для админов).

### Права (Permissions)
* `reachextender.use` — Позволяет **использовать** бонус к дальности (По умолчанию: `true`).
* `reachextender.give` — Позволяет использовать команду выдачи (По умолчанию: `op`).

## 📄 Конфигурация (`config.yml`)
Вы можете настроить плагин под свой сервер:

```yaml
item:
  material: STICK           # Материал предмета
  name: "&bМагическая Палка" # Имя предмета (поддерживает цвета &)
  lore:                     # Описание предмета
    - "&7Держи в левой руке"
    - "&7для +3 блока дистанции"

bonus-reach: 3.0           # Сколько блоков добавляется к дальности
check-interval: 10         # Частота проверки инвентаря (в тиках). 10 = 0.5 сек.
